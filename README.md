<h2>🔧 Project Overview</h2>
<p>
  <strong>FixBuddy</strong> is a web application designed to bridge the gap between customers and service providers. Whether it’s a plumbing issue or electrical repairs, FixBuddy allows users to easily book trusted professionals with just a few clicks.
</p>

<h2>🚀 Features</h2>
<ul>
  <li>User authentication and authorization</li>
  <li>JWT-based secure login system</li>
  <li>Role-based dashboards for users and service providers</li>
  <li>Book, view, and manage service appointments</li>
  <li>Admin interface for service management and user control</li>
  <li>Responsive design with seamless UI/UX</li>
</ul>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><strong>Frontend:</strong> React.js, HTML, CSS, Axios</li>
  <li><strong>Backend:</strong> Django REST Framework</li>
  <li><strong>Database:</strong> PostgreSQL</li>
</ul>

<h2>🧑‍💻 How to Run Locally</h2>
<ol>
  <li>Clone the repository</li>
  <li>Navigate to the <code>backend</code> and install Python dependencies using <code>pip install -r requirements.txt</code></li>
  <li>Run Django migrations and start the server</li>
  <li>Navigate to the <code>frontend</code> and run <code>npm install</code>, then <code>npm start</code></li>
</ol>
